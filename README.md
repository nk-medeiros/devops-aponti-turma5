# 🚀 DevOps - Turma 5 (Aponti / FAP)

Este espaço funciona como meu portfólio prático e diário de bordo na formação de **DevOps pela Aponti**. Aqui estão centralizados todos os laboratórios, automações, scripts e documentações técnicas produzidos ao longo do programa, demonstrando a aplicação real de conceitos de CI/CD, Infraestrutura como Código e governança em nuvem.
